### 0. Ayuda: modulos y acciones que encuentra solo

$ docker exec sigeru-prueba-so sigeru-admin --ayuda
sigeru-admin 1.0 (2da entrega, 12/09/2026)

Uso:  sudo /usr/local/sbin/sigeru-admin                       menu interactivo
      sudo /usr/local/sbin/sigeru-admin <modulo> <accion> [argumentos]
      /usr/local/sbin/sigeru-admin --ayuda

Modulos y acciones disponibles (cada una es una funcion <modulo>_<accion> de lib/):
  usuarios  alta baja clave listar 
  red       dns gateway ip ping puertos resumen 
  respaldo  ahora listar log restaurar 
  servicios detener estado iniciar reiniciar 

Ejemplos:  sudo /usr/local/sbin/sigeru-admin usuarios listar
           sudo /usr/local/sbin/sigeru-admin red ping 8.8.8.8
           sudo /usr/local/sbin/sigeru-admin servicios reiniciar apache2

###    Sin root no corre:

$ docker exec -u 65534 sigeru-prueba-so bash /tmp/scripts/admin/sigeru-admin.sh red ip
Este script administra el servidor: hay que correrlo como root.
    sudo /tmp/scripts/admin/sigeru-admin.sh red ip
[codigo de salida: 1]

servicios. Es lo normal dentro de un contenedor Docker, donde no hay init.
