Prueba de endurecimiento SSH - servidor sigeru-srv
Fecha: 2026-09-13

Se aplico administracion-sistemas-operativos/config/sshd_config.d/sigeru.conf en
/etc/ssh/sshd_config.d/sigeru.conf (con AllowUsers cosmos2026 en vez de sigeru: se
decidio en la instalacion usar ese usuario del sistema operativo, ver
2026-09-13-prueba-red-estatica.txt y el commit de esta fecha).

$ sudo sshd -t
sintaxis OK

$ sudo systemctl reload ssh

Configuracion activa (sudo sshd -T | grep -Ei "permitrootlogin|passwordauthentication|maxauthtries|allowusers|x11forwarding"):
maxauthtries 3
permitrootlogin no
passwordauthentication yes
x11forwarding no
allowusers cosmos2026

=== Prueba 1: cosmos2026 con clave publica (debe entrar) ===
$ ssh -p 2222 cosmos2026@127.0.0.1 "whoami"
cosmos2026

=== Prueba 2: root (debe rechazar) ===
$ ssh -p 2222 root@127.0.0.1 "whoami"
root@127.0.0.1: Permission denied (publickey,password).
